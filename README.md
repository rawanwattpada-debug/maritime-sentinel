# Maritime Sentinel

**منصة الإنذار المبكر للمخاطر البحرية.** ترصد السلوك غير الاعتيادي حول السفينة، وتقيّم الخطورة بأسباب مفهومة، وتترك القرار للإنسان.

> الذكاء الاصطناعي يستكشف، والإنسان يقرر.

مشروع هاكاثون 2026.

---

## وش يسوي النظام؟

1. **المراقبة المستمرة:** يدمج أهداف الرادار مع بيانات AIS. كل هدف رادار ما يطابق أي سفينة مسجلة يصير **هدف مظلم** (قارب بدون AIS).
2. **تقييم الخطورة:** يعطي كل هدف درجة من 0 إلى 100، ومستوى (منخفض / متوسط / عالي)، وأسباب مكتوبة بالعربي. التقييم يجمع بين قواعد ملاحية (الاقتراب، أقرب نقطة التقاء CPA/TCPA، السرعة، التنسيق بين عدة أهداف) ونموذج كشف شذوذ (Isolation Forest).
3. **التحقق البصري:** يطلق مسيّرة **بعد موافقة المشغّل**، ونموذج YOLO يتعرف على القوارب في الفيديو.

```
سفن AIS حقيقية ─┐
                ├─► رادار (محاكاة) ─► دمج رادار + AIS ─► محرك الخطورة ─► لوحة التحكم ─► قرار المشغّل ─► مسيّرة + YOLO
أهداف محاكاة ───┘                    (fusion.py)        (risk_engine.py)    (site/)
```

## النتائج

كل الأرقام تطلع من سكربتات موجودة في المشروع، وتقدرون تعيدون تشغيلها.

### 1. دمج الرادار مع AIS (`evaluate_fusion.py` → `fusion_eval.json`)
| الاختبار | النتيجة |
|---|---|
| سفن حقيقية (19 سفينة في التسجيل، رادار محاكى) | **100%** تعرّف عليها النظام صح، **0%** صُنّفت مظلمة بالغلط |
| أهداف مظلمة (11 هدف، 20 تجربة) | **100%** انكشفت، خلال **21 ثانية** تقريبًا |
| قارب يختبئ جنب سفينة مسجلة (`shadow_test.py`، 25 تجربة) | **100%** ظل مظلم، و**100%** طلع عليه تنبيه |

### 2. محرك الخطورة (`evaluate_risk.py` → `risk_eval.json`)
280 سيناريو محاكاة عشوائي (40 لكل نوع) مع خطأ رادار، و35 سفينة حقيقية.

| | النتيجة |
|---|---|
| كشف التهديدات (Recall) | **100%** (243 قارب مهاجم)، وكلها انكشفت قبل ما توصل لكيلو واحد |
| أول تنبيه عالي | على بُعد **4.3 إلى 5.1 كم**، يعني قبل الوصول بـ **5 إلى 7 دقائق** |
| الدقة (Precision) | **97.6%** |
| الإنذار الكاذب في السيناريوهات العادية | **3.3%**: الصيد 0%، القارب البطيء 0%، القارب السريع العابر 10% |
| السفن الحقيقية (35 سفينة، 9,230 قراءة) | **0 تنبيهات** |

### 3. الرؤية الحاسوبية (`site/public/media/vision_summary.json`)
YOLOv8n على 1,453 إطار: **3 قوارب** تتبّعها النموذج، بمتوسط ثقة **78%**.

## التشغيل

**الموقع ولوحة التحكم** (يحتاج Node.js):
```bash
cd site
npm install
npm run dev
```
بعدها افتحوا `http://localhost:5173`.

**بايثون** (Python 3.11 أو أحدث):
```bash
pip install -r requirements.txt
python export_demo.py         # يعيد إنتاج بيانات الديمو للموقع
python evaluate_fusion.py     # تقييم الدمج
python evaluate_risk.py       # تقييم محرك الخطورة (حوالي 10 دقائق)
python test_risk_engine.py    # اختبارات محرك الخطورة
python replay.py              # خادم بث مباشر للسفن على http://localhost:8000
```

## المصادر

- **AIS:** aisstream.io، و NOAA Office for Coastal Management (AIS 2024)
- **الطقس:** Open-Meteo (Forecast و Marine API)
- **الخريطة:** Esri World Imagery
- **أرقام العرض:** UNCTAD Review of Maritime Transport، و ICC IMB Piracy and Armed Robbery Against Ships 2025، و JMIC

## حدود النظام

- الرادار وأهداف الهجوم محاكاة، فأرقام كشف التهديدات قياس على سيناريوهات محاكاة، مو على هجمات حقيقية.
- السفن الحقيقية منقولة من مضيق دوفر، يعني حركتها حقيقية ومكانها منقول.
- فيديو المسيّرة واحد لكل الأهداف، وهو مو من البحر الأحمر.
