# أصوات الشريحة الأولى

ضعي هنا ملفين صوت بهذي الأسماء بالضبط:

| الملف | الصوت |
|---|---|
| `waves.mp3` | أمواج البحر |
| `rain.mp3` | مطر |

- يشتغل الصوت بشكل متكرر (loop)، فالأفضل تسجيل طوله دقيقة أو أكثر ويكون آخره متصل بأوله.
- استخدمي أصوات مجانية الاستخدام (مثلاً من Pixabay Sound Effects أو Freesound برخصة CC0).
- إذا الملف غير موجود، الموقع يشغّل صوت بديل مصنوع بالكود.
